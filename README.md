# Jarrett Nance — Software Development Portfolio

A static, multi-page portfolio originally created for Cleveland Community College coursework and updated to support entry-level software engineering applications.

## Structure

- `index.html`: introduction and development focus
- `about.html`: education, experience, skills, and current resume
- `artifacts.html`: public code links and coursework reflections
- `growth.html`: development goals and integrity statement
- `contact.html`: contact details and email-draft form
- `assets/css/styles.css`: shared responsive styles
- `assets/js/main.js`: navigation, mailto form, and footer year

## Run locally

From the repository root, run `python3 -m http.server 8000` and visit `http://localhost:8000`. No build step is needed.

## Resume

`assets/Jarrett_Nance_Launchpad_Resume.pdf` is the supplied current resume. `assets/Jarrett_Nance_Resume.pdf` contains the identical replacement so existing public links continue to work.

## Scope and attribution

Coursework screenshots and illustrative images are distinguished from public source code. Portfolio copy and maintenance received AI assistance. External coursework repositories are linked for review and are not modified by this portfolio.

The contact form opens the visitor's email application; it does not send or store messages on a server.
